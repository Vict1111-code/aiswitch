# Vision and strategy

Status: proposed baseline — 2026-11-25.

Provider-neutral BYOK engineering workspace for independent developers, students, researchers, freelancers and teams. Validate with 15 interviews, five prototype tests and ten pilot users. Differentiators: portable code, multiple credentials, auditable actions, evidence and cost transparency.

## Collaboration-first direction
AISwitch — Collaborative AI-Native Development Studio. Different minds. Shared intelligence. One workspace. Mission: make human–AI collaboration easy, affordable, fast, lively and secure; reduce context loss and duplicate effort. Initial audience includes small developer teams, not only individuals. Validate task completion cost and shared context quality with pilot teams.
