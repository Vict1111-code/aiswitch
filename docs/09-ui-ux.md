# UI/UX specification

Status: proposed baseline — 2026-11-25.

Navigation: Home, Chat, Projects, Code Studio, App Builder, Research, Agents, Workflows, Knowledge, Integrations, Usage, Settings. Provider settings support aliases, masked keys, model discovery and connection testing. Chat supports single, parallel and group layouts; IDE has explorer/editor/terminal/diff/assistant; research has evidence panel. Dark/light themes, keyboard shortcuts, accessible focus and responsive layouts.

## Collaboration-first UX
P0 shared project conversation, invite dialog, participant list with human/AI labels, @mentions, model selector, shared context panel, credential payer selection, budget indicator, activity feed and reconnect status. Private vs shared visibility explicit. P1 rooms, presence, task board, decision register, collaborative editor and preview; P2 meetings/whiteboard; P3 virtual office. Keyboard accessible and responsive; no AI impersonation.
