# UI/UX specification

Status: proposed baseline — 2026-11-25.

Navigation: Home, Chat, Projects, Code Studio, App Builder, Research, Agents, Workflows, Knowledge, Integrations, Usage, Settings. Provider settings support aliases, masked keys, model discovery and connection testing. Chat supports single, parallel and group layouts; IDE has explorer/editor/terminal/diff/assistant; research has evidence panel. Dark/light themes, keyboard shortcuts, accessible focus and responsive layouts.
